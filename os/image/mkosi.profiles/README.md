# Image profiles

mkosi profiles: alternative configurations of the one development image,
selected with `--profile <name>`. The base `os/image/mkosi.conf` is the x86-64
image and needs no profile.

| Profile | Decision | Target |
| --- | --- | --- |
| `pi4b-arm64/` | `FML-ADR-088` | Raspberry Pi 4B development article, arm64. |
