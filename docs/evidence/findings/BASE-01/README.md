# BASE-01 evidence

This directory records closure evidence for BASE-01, the machine-readable
remediation findings register.

`closure.md` explains why the finding is closed and identifies the independent
reviewer. `2026-09-09-verification.json` retains the machine-readable check and
red-team results whose SHA-256 hash is bound into that packet.

The evidence is `SIMULATED`. It verifies repository behavior against temporary
fixtures and makes no claim about hardware behavior.
