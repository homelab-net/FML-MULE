# Flat-sat service units

These empty test-only unit markers let the real configuration resolver prove
that an enabled catalog record names an existing deployment unit. They are not
loadable production Quadlets and never leave the test tree.

- `stand-in-alpha.container` belongs to the synthetic `stand-in-alpha` record.
- `stand-in-beta.container` belongs to the synthetic `stand-in-beta` record.
