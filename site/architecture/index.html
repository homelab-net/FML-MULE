Architecture

One node. Separate pipes. A local environment that survives the wide one.

The radios and the TAK applications already exist. The work is one reproducible host, a fixed order for losing capacity, and services that do not pretend a thin pipe is a fat one.

Stack

From the people, through the service classes, to the procedure that still works if the node is dark.

  1. End-user devices

    01

    Planning case: 4–8 authenticated phones, tablets, or laptops. CONOPS §6. The maximum is a Stage 2 question.

  2. Services, by class

    02

    S0 stays up while the node is operational. S1 is local, including peer ATAK and cached maps. S2 is shared. S3 sheds first. The finer order is CCR-02, and it is not approved.

  3. One Debian host

    03

    FML-ADR-021. Compute, storage, and local applications on a single host. The module is not chosen.

  4. Radio functions

    04

    wifi_ap, wifi_mesh, HaLow, LoRa. Ethernet where practical. HaLow and LoRa use independent chains.

  5. Routing baseline

    05

    802.11s with batman-adv in BATMAN-IV. A planning baseline, simulated in software, not a field result.

  6. PACE

    06

    Analog and manual procedures that do not use the node. Voice lives here, not in the bearer list.

Which line is which

The access point, the high-throughput mesh, HaLow, and LoRa are different functions. HaLow and LoRa do not share an antenna. WAN stops at the node.

Three teams, one canyon.

CONOPS §77 is three standard nodes: Alpha, Bravo, and Charlie. Put them in a canyon and Bravo, on the ridge, is why the floor can still reach the trailhead on HaLow. The pickup is transport. It is not the network.

CONOPS §77, placed in a canyon. Alpha is on the floor, Bravo is a full team on the ridge, Charlie is at the trailhead. Bravo is the HaLow geometry, not a relay product. The rung is DEGRADED-IP.

Phones join their own node. Across the canyon the IP path is HaLow, so lower-rate IP continues: TAK, maps, voice-class audio and PTT, moderate imagery, and browser services. HD video is not this hop. What one node keeps

Same order, one node, no terrain. The highest linked inter-node bearer sets the rung. The access point never does. Ethernet never does. WAN never does.

The default is a team off the wider network, on HaLow. That rung is DEGRADED-IP. High-throughput Wi-Fi is what would make it NOMINAL-IP. Ordering lives in mule/modes.py. This board is not a radio test.

Fault means the access point is down: stored data may remain, and the node is not serving users. LoRa never becomes an IP path. PACE does not use the node.

Replaceable functions

Swapping a radio must not require a new services design. No radio product is selected.

Identity is a target

EAP-TLS, a preferred step-ca, and a Mission Trust service that is not a CA. None of it is built.
